# Cogym School Protocol

A School is a task-specific evolutionary laboratory that converts participant experience into increasingly efficient Packs.

## Loop

`curriculum -> participant runs -> outcomes -> distilled experience -> Hydra -> variant Packs -> held-out evaluation -> certified Packs`

## Curriculum

Stages should move along an adaptive capability frontier rather than fixed “years”. Each stage defines a benchmark suite and graduation conditions. Difficulty increases when performance saturates and should deliberately target known failure modes.

## External participant agents

Participant agents are willing experimental subjects. A run should record:

- agent pseudonymous id;
- claimed model + optional model-inference proof;
- world/context/pack commitments;
- standardized output;
- outcome/evaluation;
- trace-use consent;
- abstract reward/credit receipt.

Do not require raw private chain-of-thought. Cogym needs structured rationale artifacts, forecasts, decisions, evidence, assumptions, and revisions. This is sufficient for evolution and much safer/cleaner to exchange.

## What the School owns

- immutable world corpus;
- curricula and evaluator versions;
- derived method/reasoning memories;
- aggregate behavioral graph;
- Pack variants + certificates.

Participant-private memory remains separate unless explicitly contributed.
