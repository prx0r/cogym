# Research Basis (Aug 20 2026)

The architecture intentionally combines:

- BEAM/LIGHT: episodic + working + compressed scratchpad memory;
- ReasoningBank: distill reusable strategies from successes and failures;
- MemEvolve: memory architecture itself can become an optimization variable;
- varied-context collaboration findings: exemplars/context can help or distract, so retrieval must be experimentally evaluated rather than assumed useful;
- DeepProve: end-to-end inference proving for supported open models;
- Loom: Rust modularity/provider isolation/thread persistence/telemetry as engineering reference;
- PZL: constructor/scenario/instance hierarchy, deterministic seeds, verification contracts;
- EvoLabz: multi-timescale market-state vectors, regime transitions and regime-conditioned evaluation.
