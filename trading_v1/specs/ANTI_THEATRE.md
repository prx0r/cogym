# Anti-theatre contract

1. Harness models test plumbing, never cognition claims.
2. No manually generated "convergence" values count as evidence.
3. Candidate Packs remain candidate until real-model held-out experiments exist.
4. No arbitrary composite fitness score unless its weights are justified for a named experiment.
5. Never claim a hash or zk proof proves intelligence/capability.
6. Never infer an inaccessible internal mental state solely from prose style.
7. Hidden test worlds never enter teacher reflection or pathway optimization.
8. If a remote adapter has not been exercised with real credentials, call it an adapter boundary, not an integration.
9. Do not add blockchain, Rust, HydraDB, GPUs or orchestration merely because they sound production-grade.
10. Every new subsystem must fix a demonstrated research-quality or decision-quality failure.
