# Research notes / starting bibliography

These are conceptual anchors, not bundled dependencies:

- Hendel, Geva, Globerson — *In-Context Learning Creates Task Vectors* (2023).
- Todd et al. — *Function Vectors in Large Language Models* (2023/ICLR 2024).
- *Persona Vectors* (2025) — behavioral traits as activation-space directions.
- *Steer Like the LLM / Prompt Steering Replacement* (ICML 2026) — prompt effects are dynamic across tokens rather than one static steering direction.
- *From Simulation to Enaction: Post-trained language models recognize and react to their own generations* (2026) — relevant to self-generated vs externally supplied trajectory conditions.
- SELF-DISCOVER (2024) — task-specific reasoning structures.
- Promptbreeder (2023), GEPA (2025) — evolutionary prompt/procedure optimization.
- ADAS, AFlow, AgentSquare — search over agent/workflow structure.
- ReasoningBank (2025) — reusable lessons from successful and failed trajectories.
- MemEvolve (2025) — evolution of memory architecture.
- Quality Diversity / MAP-Elites and Novelty Search — preserve distinct useful cognitive niches rather than one global winner.
- POET / Population Based Training — co-evolving environment difficulty and populations.
- full-information expert-learning / universal portfolio literature — useful when every simulated decision can be scored against the same future.

The implementation deliberately does not assume any of these mechanisms will improve trading decisions. Cogym exists to test such claims in frozen worlds.
