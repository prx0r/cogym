# Transmission

A **skill** is an instruction/resource an agent can consult.

A **transmission** is an interaction designed by an already-conditioned teacher to induce a useful cognitive regime in another fresh agent.

The recipient must normally generate intermediate judgments itself. Reading the teacher's final conclusion is a different experimental condition.

## Transmission object

- teacher/master ID;
- teacher state/context commitment;
- pre-intervention student diagnosis;
- precommitted prediction of expected change;
- ordered live pathway;
- parent transmission ID if evolved;
- post-intervention evidence IDs.

## Master/student loop

1. fresh student takes baseline training probes;
2. Master predicts the student's failure mode;
3. Master emits transmission;
4. student undergoes it live;
5. student is evaluated on disjoint validation worlds;
6. Master receives permitted outcome summaries;
7. Master reflects in the same persistent context;
8. next fresh student arrives.

Hidden final-test worlds must not leak into Master reflection.

## Transmission chains

A conditioned student may author the next student's transmission. A -> B -> C chains test cultural fidelity, drift and mutation.
